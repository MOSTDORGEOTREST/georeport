# ПРОМТ: фирменный дизайн в стиле МДГТ / GEOREPORT

> Скопируй весь текст ниже и вставь в начало задачи. Он самодостаточен: содержит все токены, правила и чек-листы, чтобы получить готовый дизайн за один заход.

---

Ты — продуктовый дизайнер и фронтенд-инженер. Сделай интерфейс проекта в едином фирменном стиле, описанном ниже. Ничего не выдумывай сверх этой системы: все цвета, шрифты, радиусы, тени и анимации бери строго из токенов. Результат должен выглядеть как продукт одной студии с сайтом инженерной лаборатории: тёмный «инженерный» синий, янтарный акцент, тёплые бумажные поверхности, крупная дисплейная типографика и моноширинные технические подписи.

## 1. Настроение и характер

Стиль: «инженерная лаборатория премиум-класса». Смесь редакционной вёрстки (крупные заголовки, много воздуха) и технического HUD (моноширинные надзаголовки с большой разрядкой, табличные цифры, пунктирные линии-разметки). Тёмные секции выглядят как ночная шахта с янтарной подсветкой, светлые — как плотная тёплая бумага. Ничего «корпоративно-голубого», никаких чисто-белых фонов, никакого фиолетового/розового AI-градиента.

## 2. Дизайн-токены (CSS-переменные, использовать буквально)

  --card: #FBF8F1;            /* фон карточек */
  --surface-elevated: #FFFDF6;/* поля ввода, выпадающие меню */

  /* Тёмные секции (hero, акцентные блоки) */
  --dark: #111826;
  --dark-2: #141B2A;          /* градиент: linear-gradient(150deg, var(--dark), var(--dark-2)) */
  --dark-ink: #F4EFE4;        /* текст на тёмном */
  --dark-ink-dim: #C9C2B2;
  --dark-muted: #948E80;
  --dark-line: rgba(244,239,228,.13);

  /* Чернила на бумаге */

  --text-secondary: rgba(34,26,14,.68);
  --text-muted: rgba(34,26,14,.52);

  /* Акцент — ЯНТАРЬ (единственный акцентный цвет) */
  --amber: #E8A33D;           /* на тёмном фоне */
  --amber-hi: #FFC96B;
  --amber-deep: #8F5A10;
  --accent: #A66A14;          /* янтарь для светлых поверхностей (контраст ≥4.5:1) */

  /* Статусы */

  --danger: #B3402F;
  --danger-soft: rgba(179,64,47,.09);

  /* Линии и тени */
  --line: rgba(34,26,14,.16);

## 3. Типографика

Три шрифта, всегда локальные woff2 (subsets latin + cyrillic), `font-display: swap`:

- **Unbounded** (400/600/800) — `--font-d` — ТОЛЬКО заголовки h1/h2, крупные цифры-метрики, названия брендов. h1: `clamp(2.1rem, 5vw, 3.4rem)`, line-height 1.05, weight 800. h2 секций: weight 600. Никогда не использовать для абзацев.
- **Inter** (300/400/500/600) — `--font-s` — весь текст. Базовый размер 16px (15px на мобиле), line-height 1.65. Лид-абзацы — weight 300.
- **JetBrains Mono** (400/500) — `--font-m` — «технический голос»: надзаголовки-eyebrow, лейблы форм, заголовки таблиц, даты, счётчики, чипы, подписи в футере. Все цифры с `font-variant-numeric: tabular-nums`.

Фирменный приём — **mono-eyebrow**: строка над заголовком в JetBrains Mono, uppercase, font-size 0.64–0.7rem, letter-spacing 0.3–0.4em, цвет янтарь. Часто с пульсирующей зелёной точкой (7px, box-shadow свечение, `animation: pulse 2s infinite`).

## 4. Компоненты

**Кнопки** — только пилюли (`border-radius: 99px`), min-height 46px, gap 0.6rem с иконкой:
- Primary: `background: var(--accent-gradient); color: #231604;` тень `0 8px 26px rgba(232,163,61,.32)`; hover: `translateY(-2px)` + усиление тени; главная CTA может пульсировать тенью (`glow 3s infinite`).
- Ghost: прозрачная, `1px solid var(--line)` (на тёмном — `--dark-line`); hover: янтарная рамка + текст + `--accent-soft` фон.
- Danger: градиент `#A23A2A → #C4503C`.

**Карточки**: фон `--card`, `1px solid var(--line-soft)`, radius 18–26px, `--shadow-card`; hover: `translateY(-3…-5px)` + `--shadow-card-hover` + янтарная рамка `rgba(166,106,20,.45)`. Акцентные карточки — `border-left: 3px solid` цвета статуса.

**Тёмная hero-карточка**: радиус 26px, градиент `--dark → --dark-2`, поверх — зерно-шум (SVG feTurbulence, opacity .22, mix-blend-mode overlay) и мягкое янтарное радиальное свечение в углу (`radial-gradient(circle, rgba(232,163,61,.28), transparent 65%)`, blur 14px). Внутри: mono-eyebrow с live-точкой → h1 (Unbounded 800, ключевое слово залито `--accent-gradient` через background-clip: text) → лид (300) → кнопки → чипы-пилюли в mono → mono-подпись мелким кеглем.

**Поля ввода**: фон `--surface-elevated`, `1px solid var(--line)`, radius 12px, min-height 46px; focus: янтарная рамка + `box-shadow: 0 0 0 3px var(--accent-soft)` + белый фон. Лейблы — mono uppercase 0.64rem, letter-spacing 0.16em. На мобиле font-size ≥16px (iOS-зум).

**Таблицы**: заголовки — mono uppercase 0.62rem, letter-spacing 0.18em, muted; разделители строк — `1px dashed var(--line-soft)`; hover строки — `rgba(232,163,61,.06)`; даты/числа — mono, tabular-nums. На ≤768px таблица превращается в карточки.

**Чипы/бейджи**: пилюли, mono 0.72rem; варианты: янтарный (`--accent-soft` + рамка), зелёный (`--green-soft`), нейтральный (рамка `--line`).

**Модалки**: центр, скрим `rgba(14,11,7,.55)` + `backdrop-filter: blur(6px)`, карточка `--surface-elevated` radius 18px, появление `scaleIn 0.25s`; заголовок Unbounded 600. Esc и клик по скриму закрывают.

**Тосты**: справа сверху, карточка с `border-left: 3px solid` цвета статуса, `slideUp 0.3s`.

**Навбар**: фиксированный, `rgba(242,236,223,.75)` + `backdrop-filter: blur(16px)`; при скролле — плотнее фон, нижняя граница `--line-soft`, тень. Логотип — в светлом чипе (фон #F6F2E8, radius 12px, рамка). Название — Unbounded 600 0.82rem letter-spacing .1em, под ним mono-подпись 0.56rem. Ссылки: 0.85rem, hover — тонкое янтарное подчёркивание, «рисующееся» слева (`transform: scaleX`, transform-origin переключается). CTA в навбаре — маленькая янтарная пилюля. **≤900px — бургер** (44px, рамка) и полноэкранный/боковой drawer на бумажном фоне.

**Футер**: фон `--bg-secondary`, верхняя граница; колонки, заголовки колонок — mono uppercase янтарные с letter-spacing 0.28em; ссылки с пунктирным подчёркиванием на hover; низ — копирайт и mono-слоган, разделитель `1px dashed var(--line)`.

**Бегущая строка (опционально, 1 шт. на страницу)**: лента фона `--green`, radius 18px, маска-градиент по краям; внутри бесконечный marquee (28s linear) из слов в Unbounded 800 uppercase — чередовать контурные (`color: transparent; -webkit-text-stroke: 1px rgba(244,239,228,.5)`) и залитые янтарём.

## 5. Динамика (вся — с уважением к prefers-reduced-motion)

- **Вход hero**: каскад `slideUp 0.8s var(--ease)` с задержками 60/140/240/340/440/540ms (eyebrow → заголовок → лид → кнопки → чипы → подпись).
- **Scroll-reveal**: секции и карточки ниже фолда — opacity 0 + translateY(26px) → появление через IntersectionObserver (threshold 0.08, rootMargin -8%), transition 0.7s var(--ease), стаггер 80–130ms; страховочный таймер ~5s на случай несработавшего наблюдателя; элементы уже во вьюпорте показывать сразу.
- **Микро**: hover-подъём карточек; иконка в карточке — `scale(1.08) rotate(-4deg)`; числа-метрики — count-up ~900ms cubicOut при появлении; прогресс-бары — анимация ширины 0.8s.
- Переходы 150–300ms; transform/opacity, без анимации layout-свойств.

## 6. Сетка и адаптив

Контейнер `--wrap` (max 1080px), паддинги 1.5rem (1rem на мобиле). Секции разделяет вертикальный ритм 3–4.5rem. Брейкпоинты: 480 / 768 / 900 / 1080. Обязательно проверить 360, 390, 768, 860, 1024, 1440: ни горизонтального скролла, ни наложений; двухколоночные блоки складываются в колонку ≤900px; touch-таргеты ≥44px.

## 7. Совместимость и качество (чек-лист, выполнить всё)

- [ ] Инпуты ≥16px на мобиле (iOS не зумит), `-webkit-text-size-adjust: 100%`.
- [ ] `backdrop-filter` всегда с `-webkit-` префиксом; `background-clip: text` — с `-webkit-`.
- [ ] `:focus-visible` — янтарная обводка 2px offset 3px; фоллбек через `@supports not selector(:focus-visible)`.
- [ ] `prefers-reduced-motion: reduce` — отключить все анимации/marquee/параллакс.
- [ ] Скроллбары: `scrollbar-color` (Firefox) + `::-webkit-scrollbar` в тонах бумаги/янтаря.
- [ ] `@media print`: белый фон, спрятать шапку/футер/баннеры/кнопки (`.no-print`), контент — как чистый документ.
- [ ] Контраст текста ≥4.5:1 (на светлом использовать `--accent` #A66A14, не #E8A33D).
- [ ] Иконки — только SVG-набор (Remix/Lucide), никаких эмодзи; у всех интерактивных элементов cursor: pointer и aria-атрибуты.
- [ ] `::selection` — янтарный фон, тёмный текст. Шрифты — preload двух ключевых woff2.
- [ ] Никаких CDN в рантайме: шрифты и иконки — локально.

## 8. Запрещено

- **Многоцветные декоративные полоски/градиенты из нескольких цветов на краях карточек и виджетов — НИКОГДА.** Все декоративные акценты строго одноцветные: янтарная линия, янтарное свечение, пунктир.
- Чисто-белые фоны страниц, голубой «корпоративный» синий, фиолетово-розовые AI-градиенты.
- Unbounded в абзацах; более трёх шрифтов; радиусы меньше 12px у крупных блоков.
- Резкие тени без размытия; чёрный #000; серые холодные оттенки (все нейтрали — тёплые, на базе #221A0E).

1. Создай файл токенов/тему из раздела 2–3 и подключи шрифты.
2. Собери базовые компоненты (раздел 4) и проверь их в светлом и тёмном блоке.
3. Свёрстай страницы: тёмный hero → светлые секции с mono-eyebrow → CTA-карточка → футер.
4. Добавь динамику (раздел 5).
5. Пройди чек-листы 6–7, сделай скриншоты на 360/768/1024/1440 и убери любые наложения.
